# S'WATCH

A single-screen watch house built around one hero: a tan frame, a dark textured card, and four cases you can move through.

## Run

```bash
npm install
npm run dev
```

The dev server listens on [http://127.0.0.1:4179](http://127.0.0.1:4179).

## What you can do

- Move between cases with the numbers, the scroll mark, a swipe on the watch, or the left and right arrow keys.
- Switch the Men and Women lines.
- Search both collections.
- Add a watch to the cart, change quantity, and reserve an order.
- Keep pieces on a list for this visit.
